# Учёт автомобилей в автопарке

Учебное настольное приложение на Python и PyQt6, сделанное на основе интерфейса «Игровая коллекция».

## Возможности
- Вход по имени пользователя (без пароля, это не система безопасности).
- Таблица автомобилей: модель, тип, статус, год, стоимость аренды за сутки.
- Добавление и удаление с подтверждением (клавиша Delete тоже работает).
- Поиск по названию и фильтр по статусу.
- Подсчёт автомобилей по статусам.
- При закрытии создаётся `report.txt` с логином и временем входа/выхода.

Данные в этой учебной версии хранятся **только в памяти**: после перезапуска восстанавливаются демонстрационные автомобили. Это соответствует исходному примеру.

## Как запустить

1. Установить Python 3.10 или новее.
2. Открыть терминал в папке проекта.
3. Выполнить:

```bash
python -m pip install -r requirements.txt
python main.py
```

## Структура
- `main.py` — запуск программы.
- `models.py` — абстрактный класс Entity, базовый Car и три дочерних класса.
- `collection.py` — Fleet, список автомобилей, поиск, добавление и удаление.
- `widgets.py` — собственные виджеты PyQt6.
- `windows.py` — окно входа, основное окно и форма добавления.
- `report.py` — сеанс пользователя и текстовый отчёт.

## ООП для защиты
- **Наследование:** PassengerCar, SUV и Minibus наследуются от Car.
- **Полиморфизм:** у разных типов автомобилей метод `kind()` возвращает свой тип.
- **Инкапсуляция:** свойства `name`, `status`, `price`, `year` проверяют данные; внутренние поля начинаются с `_`.
- **Абстракция:** класс Entity задаёт общий метод `sort_key()`, а Car требует реализовать `kind()`.
- **Композиция:** Fleet содержит список объектов Car.
- **Специальные методы:** `__eq__`, `__lt__`, `__len__`, `__str__`.

**Примечание:** два автомобиля одной модели и года считаются дубликатами. Для реального автопарка стоило бы добавить госномер и сохранение в базу данных.
